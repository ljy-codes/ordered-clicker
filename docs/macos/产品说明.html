01安装与首次启动

  1. 确认芯片与系统

    点击屏幕左上角  → 关于本机。系统需为 macOS 13 或更新版本，按 M 系列 / Intel 选择安装包。

  2. 安装到“应用程序”

    双击 DMG，将“有序连点器.app”拖到旁边的 Applications 文件夹。复制完成后，推出磁盘镜像。

  3. 从“应用程序”启动

    打开 Finder → 应用程序 → 有序连点器。若系统提示无法验证开发者，确认文件来源后，打开“系统设置 → 隐私与安全性”，在本次拦截记录处选择“仍要打开”。

  4. 授予所需权限

    在软件“模式”页点击“授权辅助功能”，在系统设置中允许“有序连点器”。需要使用画面稳定检测时，再点击“授权屏幕录制”。返回软件点击“重新检查”；系统要求退出重开时照做。

请从“应用程序”运行，不要直接在 DMG 中长期运行。更换或更新应用后，如果权限失效，可在对应权限列表移除旧条目，再添加当前应用。

02五步完成一次任务

  1. 模式：选择本机或云桌面

    普通桌面操作选择“本机坐标”。远程桌面选择“云桌面相对坐标”，点击“校准云桌面区域”，将鼠标分别移到可视区域左上角、右下角，各按一次采点键。区域需位于同一显示器。

  2. 方案：设置名称、循环和默认时间

    在“方案”页新建或打开 .oclick，设置总循环次数、轮间等待、默认点击间隔与点后等待。时间单位为毫秒，1000 ms = 1 秒。“应用全部”可批量更新已有点位。

  3. 采点：按顺序记录目标位置

    点击“开始采点”，将鼠标移到第一个目标，按 F6 记录，再依次记录其他目标。按 F8 结束采点。也可使用“2 秒后记录”，再次发起会替换上一次延迟采点。

    返回列表后，设置每个点的点击次数、间隔和点后等待；通过上移 / 下移调整顺序，取消勾选可跳过点位。完成后保存方案。

  4. 检查：确认坐标与执行计划

    根据需要开启“等待画面稳定”，设置采样间隔、稳定时长、超时和变化容差。点击“生成并确认执行计划”，查看启用点位、循环、点击总数与预计耗时。修复提示的问题后再执行。

  5. 运行：倒计时后切换目标应用

    进入“运行 / 日志”，点击“开始执行”并确认。3 秒倒计时内切换至目标窗口，保持其可见且位置不变。F7 暂停 / 继续，F8 停止。任务结束后，可打开执行日志查看结果。

04方案、云桌面与恢复

方案管理

“保存”更新当前方案；“另存为”创建新的方案身份。外部修改冲突会阻止覆盖，请改为另存。“迁移旧 JSON”用于转换 1.x 旧方案，保留原文件。

Windows v4 .oclick 可读取，但绝对坐标需重新采点。云桌面方案可在重新校准区域后使用原有相对点位，仍需检查远程页面布局。

云桌面使用

校准时只框选远程桌面的可操作画面，避开客户端工具栏和黑边。窗口移动或缩放后重新校准，再检查执行计划。

远程客户端需保持可见并允许鼠标输入。页面布局改变后应重新采点；相对坐标不会识别按钮内容。

草稿与断点

未保存修改会自动保存为草稿，下次启动恢复。“从断点继续”要求方案与显示器状态匹配，并由用户确认后运行。

异常退出时最近一小段点击可能尚未记入断点。恢复前检查目标页面，避免重复操作。正常退出会先停止任务并保存状态。

日志与数据

执行日志记录计划、计数、耗时与结果；诊断日志用于排查错误。可在“运行 / 日志”页直接打开。

数据位于 ~/Library/Application Support/OrderedClicker/。卸载应用不会自动删除方案与日志。

05常见问题

点击没有反应，或检查提示权限未授权

确认“系统设置 → 隐私与安全性 → 辅助功能”已允许当前应用。重新打开软件并点击“重新检查”。画面稳定检测还需要“屏幕录制”权限。权限撤销、锁屏或显示器变化时任务会停止。

快捷键被占用，或者按 F6 触发了系统功能

进入设置改用组合快捷键。三个操作的快捷键不能重复；注册失败时软件会显示原因，并阻止开始任务。Fn 键设置可在系统键盘设置中调整。

画面稳定检测一直暂停

检查检测区域内是否有动画、视频、计时器或持续变化的内容。优先使用云桌面校准区域缩小范围；适度调整变化容差、稳定时长或超时。确认页面已可操作后按开始 / 暂停键继续；不需要该功能时可关闭它。

换显示器、分辨率或另一台电脑后无法执行

本机坐标点位请重新采集。云桌面方案请重新校准区域。软件会检查显示器、缩放、点位范围及安全角重叠，不会直接沿用已失效的位置。

点位会点击哪一个窗口

软件按屏幕位置发送鼠标点击。执行时目标窗口需处于可见位置，避免其他窗口覆盖；采点完成后不要改变页面布局。可用状态浮窗随时停止。

如何升级、备份与卸载

升级前停止任务并退出应用，将新版复制到“应用程序”替换旧版。备份可复制 .oclick 文件或整个数据目录。卸载时将应用移入废纸篓；如需删除用户数据，请先备份方案再手动删除数据目录。
