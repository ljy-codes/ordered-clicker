# 有序连点器全局点位时间设置设计

## 目标

在保留每个点位独立编辑能力的基础上，增加点击间隔和点后等待的批量设置，减少点位较多时的重复输入。

## 交互设计

主界面在方案信息与点位表格之间增加“点位时间批量设置”栏：

- `点击间隔(ms)` 数值框，范围 10 到 600000，按钮“应用全部”。
- `点后等待(ms)` 数值框，范围 0 到 600000，按钮“应用全部”。

两个按钮互相独立：

- 应用点击间隔只修改所有点位的 `ClickIntervalMs`。
- 应用点后等待只修改所有点位的 `AfterDelayMs`。
- 应用后仍可直接编辑表格中的单行数值，单行修改不反向改变全局默认值。
- 没有点位时允许调整全局值，该值作为后续采点的默认时间。

## 数据与兼容性

`ClickProfile` 增加：

- `DefaultClickIntervalMs`，默认 100。
- `DefaultAfterDelayMs`，默认 500。

保存方案时版本升级为 2，并持久化两个默认值。加载版本 1 的旧方案时：

- 有点位：使用第一个点位的两个时间作为全局默认值。
- 无点位：使用 100ms 和 500ms。
- 原有每行点位数据保持不变。

新采集点直接使用当前两个全局数值，之后仍可单独修改。

## 代码边界

- `PointTimingService` 负责两个批量更新操作和旧方案默认值解析。
- `MainForm` 只负责界面控件、事件绑定和采点时读取默认值。
- 点击执行引擎不做修改，继续只读取每个 `ClickPoint` 的最终参数。

- 旧方案正确加载，新方案保存后可往返读取。
