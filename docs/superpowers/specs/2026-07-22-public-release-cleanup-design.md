# 有序连点器公开化与授权仓库清理设计

## 目标

- 保留公开仓库 `ljy-codes/ordered-clicker` 作为唯一连点器项目仓库。
- 明确应用永久免费使用，不需要授权码、激活、机器码或联网验证。
- 删除不再使用的 `ordered-clicker-pro` 和 `ordered-clicker-license-server` GitHub 仓库。
- 保持现有点击、热键、主题、DPI、多显示器和配置功能不变。

## 当前事实

- 公共仓库的应用源码中不存在授权校验、功能门控或激活接口调用。
- 当前安装包和便携包已经可以直接使用，没有设备数、期限或联网限制。
- 专业版仓库相对公共版本只增加了商业授权设计文档和私有仓库说明。
- 授权服务仓库只有规划说明，没有可运行的授权服务代码。

## 实施方案

1. 在公共仓库 README 中显著说明永久免费、无需授权码和无需联网。
2. 不修改点击引擎和用户配置格式，避免产生兼容性风险。
3. 执行现有自动化测试和 Release 构建检查，确认公开版功能正常。
4. 推送公共仓库说明变更。
5. 删除 GitHub 私有仓库：
   - `ljy-codes/ordered-clicker-pro`
   - `ljy-codes/ordered-clicker-license-server`
6. 保留其他无关 GitHub 仓库，不修改其可见性和内容。

## 本机数据边界

- 本次不删除 `D:\专用工具\连点器专业版`。
- 本次不删除 `D:\专用工具\连点器授权服务`。
- 本次不删除 `D:\专用工具\连点器私有资料` 或历史授权码库存。
- 上述本机目录仅作为历史备份，不再参与公开版构建和发布。

## 验证标准

- 公共仓库 README 明确写明无授权限制。
- 源码扫描不存在授权、激活或机器码校验。
- 自动化测试通过。
- `ordered-clicker` 仍为公开仓库。
- 两个已确认的私有仓库在 GitHub 上不存在。
- 其他 GitHub 仓库未被修改。

## 风险与回滚

- 删除 GitHub 仓库不可直接撤销，因此删除前保留本机完整 Git 历史。
- 公共仓库只修改文档，不改变程序行为；如说明有误，可通过 Git 回滚提交。
- 本机历史目录保留，可在误删远端后重新创建仓库并推送恢复。
