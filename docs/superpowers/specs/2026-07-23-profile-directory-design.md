# 方案目录与快速切换设计

## 目标

在主界面“方案名称”位置增加本机方案目录能力，让普通用户可以通过下拉列表快速选择方案，并通过文件夹按钮打开方案文件目录。

本功能只管理程序默认方案目录：

`%LocalAppData%\OrderedClicker\profiles`

不扫描最近文件、不记录外部目录，也不改变现有“保存”“另存为”“导入方案”“导出方案”的职责。

## 界面设计

1. 将现有方案名称 `TextBox` 替换为可编辑 `ComboBox`。
2. 下拉框保持现有宽度和输入能力，用户仍可直接输入或修改方案名称。
3. 在下拉框右侧增加文件夹图标按钮。
4. 文件夹按钮使用简洁图标和工具提示“打开方案目录”。
5. 下拉列表显示默认方案目录内所有 `*.json` 文件，按文件名自然排序。
6. 每次展开下拉列表时重新扫描目录，确保新保存、删除或手工复制的文件能及时显示。
7. 连点执行期间，下拉框和文件夹按钮都禁用，避免执行中切换配置。

## 方案切换

### 选择本机方案

1. 用户展开下拉列表并选择一个方案文件。
2. 程序先判断当前界面内容是否相对最近一次保存或加载发生变化。
3. 没有未保存修改时，直接校验并加载所选方案。
4. 有未保存修改时，弹出“保存 / 不保存 / 取消”提示：
   - 保存：先执行当前方案的保存逻辑，保存成功后再切换。
   - 不保存：放弃当前修改并切换。
   - 取消：恢复原下拉选项，不切换方案。

### 加载语义

下拉列表中的文件属于本机方案，不按“导入副本”处理：

- 加载成功后绑定该 JSON 文件路径。
- 后续点击“保存”覆盖当前绑定文件。
- “另存为”仍可将其保存为其他文件。
- “导入方案”仍用于外部文件，并继续执行副本保护逻辑。
- “导出方案”仍只生成备份，不改变当前绑定路径。

### 加载失败

如果文件损坏、版本不支持或点位参数非法：

- 显示明确错误信息。
- 当前方案、点位、循环参数和保存路径保持不变。
- 下拉框恢复到切换前的显示内容。

## 未保存状态判断

程序保存一份“最近成功保存或加载的方案快照”作为基准。

在切换方案前，将当前界面生成标准化方案快照，与基准逐项比较：

- 方案名称
- 总循环次数和轮间等待
- 全局点击间隔和点后等待
- 云桌面模式、区域和稳定等待参数
- 点位数量、顺序、启用状态
- 坐标、点击次数和单点时间
- 显示器和 DPI 信息

保存、另存为或本机方案加载成功后更新基准。导入外部方案成功后视为未保存副本，首次保存仍按现有规则要求另存为。

## 方案目录按钮

1. 点击文件夹按钮时确保默认方案目录存在。
2. 使用 Windows 资源管理器打开该目录。
3. 打开失败时显示受控错误，不影响当前方案。
4. 用户从资源管理器返回后，再次展开下拉列表即可看到目录变化。

## 服务边界

### ProfileService

增加默认目录方案枚举能力：

- 只返回默认方案目录中的 `.json` 文件。
- 返回规范化完整路径和用于显示的文件名。
- 使用稳定、大小写不敏感的自然排序。
- 目录不存在时创建目录并返回空列表。

现有保存、导入、导出和副本防覆盖逻辑保持不变。

### MainForm

负责：

- 下拉框刷新和选中项恢复。
- 未保存修改确认。
- 调用 `ProfileService` 校验并加载本机方案。
- 更新当前绑定路径和基准快照。
- 打开方案目录。
- 执行期间控制相关控件状态。

## 兼容性

- 继续支持版本 1 至 3 的方案 JSON。
- 原有默认方案路径保持不变。
- 原有保存、另存为、导入和导出按钮保留。
- 外部导入方案继续使用副本文件名，并禁止覆盖来源文件。
- 不修改执行引擎、坐标换算、云桌面校准和快捷键逻辑。

## 测试

自动化测试覆盖：

1. 默认目录不存在时返回空列表并创建目录。
2. 只列出 `.json` 文件，忽略其他文件。
3. 方案文件按文件名稳定排序。
4. 本机方案加载成功后绑定文件路径。
5. 损坏方案切换失败时不改变当前界面。
6. 有未保存修改时触发保存确认逻辑。
7. 取消切换时恢复原选项。
8. 保存成功后刷新下拉目录。
9. 执行期间方案下拉框和文件夹按钮禁用。
10. 主界面在最小窗口尺寸和不同主题下不出现文字溢出或控件重叠。
