# 有序连点器 2.2.0

本版修复执行恢复、连续点击定位、方案保存和 macOS 采点等问题，增加执行前核对及窗口保护。

## 新增

- 演练：按启用点位移动鼠标，不发送点击或鼠标释放，不改变正式执行断点。
- 单步：完成一个点位的全部连击、点击间隔、点后等待及稳定检测后暂停，继续时先倒计时。
- 可选目标窗口绑定：检查前台应用、窗口标题与落点窗口；不匹配或被遮挡时暂停。
- 自定义局部稳定检测区域：两角选择、预览和清除，本机模式也可启用稳定检测。

## 修复

- Windows 重启后优先恢复完整方案快照及执行断点，匹配方案重新打开时保留断点；坏草稿不再连带隔离有效旧断点。
- 每次点击重新定位，恢复后重新检查；鼠标偏移、实际落点不在绑定窗口时暂停。
- 切换方案清空撤销历史，批量时间调整支持撤销。
- 启动、断点继续及运行中检查显示环境；显示器、DPI 或会话变化停止输入并保留进度，包括远程桌面断开。
- 方案保存保留正式路径，恢复旧保存流程遗留的有效副本，加载内容与冲突检测哈希来自同一次读取。
- 设置暂时无法读取时保留原文件，损坏文件隔离失败仍可启动，避免默认设置静默覆盖原文件。
- 锁定或无法删除的日志不会导致清理越界或无限循环。
- macOS 编辑坐标时更新相对坐标，未完成的校准草稿仍可恢复。
- macOS 快捷键按顺序记录按键时坐标，旧 HUD 关闭不再取消新采点。
- GitHub Release 仅替换精确同名附件；全部临时上传成功后才开始替换，保留其他平台及其他附件。
- 深色主题禁用按钮使用可读文字颜色，运行按钮分行显示。

## 兼容性与验证范围

- 保持 `.oclick` v4，兼容 2.0.0 / 2.1.0 方案；新增字段缺省时沿用旧行为。
- 旧版程序不能提供本版的窗口保护。窗口绑定需在对应平台重新设置。
- Windows 安装版、免安装版和新版 HTML/PDF 说明采用 2.2.0 版本。
- macOS 在 Windows 上完成托管编译及假平台无头回归；双架构原生编译、权限、真实输入、签名与公证仍需 Mac 实机验收。本次不上传未经验证的新 Mac DMG。
- Windows 产物未配置 Authenticode 代码签名。自动化回归使用假鼠标，不向用户桌面发送真实点击。
